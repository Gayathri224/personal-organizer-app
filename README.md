📋 Personal Organizer App (Python)
✨ Description
The Personal Organizer App is a Python-based command-line application that helps users manage their daily tasks, expenses, contacts, notes, and utilities — all in one place!

It’s built using simple Python concepts like loops, functions, dictionaries, and file handling (JSON), making it a great beginner-to-intermediate project.

🛠️ Features
📌 1. To-Do List
Add tasks

View saved tasks

Data is saved in todolist.json

💸 2. Expense Tracker
Add expenses (name + amount)

View total spent

Save/load expense data (optional extension)

📇 3. Contact Book
Add name, phone number, pincode

View saved contacts

Data is saved in contacts.json (optional)

🗒️ 4. Notes App
Add notes with title and content

Remove notes by title

Save/load notes (optional)

🧰 5. Utilities Menu
Includes:

Age Calculator

Birthday Countdown

Password Generator

Typing Speed Test (with WPM)
